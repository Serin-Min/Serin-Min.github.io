# serin-min.github.io

Personal academic website of Serin Min.

Live at https://serin-min.github.io

Built with [Jekyll](https://jekyllrb.com/) on the
[Academic Pages](https://github.com/academicpages/academicpages.github.io) template,
hosted on GitHub Pages.

## Structure

| Path | Contents |
| --- | --- |
| `_pages/` | Top-level pages |
| `_publications/` | Journal articles and manuscripts in progress |
| `_patents/` | Registered patents |
| `_talks/` | Conference presentations |
| `_portfolio/` | Research and applied projects |
| `files/` | CV and other downloads |
